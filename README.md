# E-commerce Web Application

## Overview

This project is a frontend e-commerce web application built using JavaScript, Vite and Tailwind CSS.

It provides a shopping interface where users can browse product categories, view products and interact with a shopping cart. The interface also includes a cart drawer, item count and total cost display.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Vite
- Tailwind CSS
- Flowbite
- Animate.css
- SweetAlert2

## Features

- E-commerce homepage and product browsing interface.
- Product category navigation.
- Shopping cart drawer.
- Cart item count display.
- Cart total calculation display.
- Search interface element.
- Responsive styling with Tailwind CSS.

## Installation and Setup

### Prerequisites

- Node.js
- npm

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Htoo10/vite-ecommerce-app.git
cd vite-ecommerce-app
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL displayed in your terminal.

### Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
